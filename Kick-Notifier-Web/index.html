Kick Notifier

Know when you get disconnected.Sabe quando caíste do servidor.

Client-side Fabric mod. When you get kicked, the server goes down or your connection drops, you get a Discord message with the reason. Perfect for AFK sessions.Mod de cliente para Fabric. Quando és kickado, o servidor vai abaixo ou perdes a ligação, recebes uma mensagem no Discord com o motivo. Ideal para quem deixa o jogo AFK.

How to set upComo configurar

1

Install the modInstala o mod

Put the kick-notifier jar for your version in the mods folder, together with Fabric API.Mete o kick-notifier da tua versão na pasta mods, junto com o Fabric API.

2

Create a webhook in DiscordCria um webhook no Discord

In your server, hover over the channel where you want the alerts and click the Edit channel gear.No teu servidor, passa o rato pelo canal onde queres receber os avisos e clica na roda dentada Edit channel (Editar canal).

In the left menu, open Integrations and click Create webhook.No menu da esquerda, abre Integrations (Integrações) e carrega em Create webhook (Criar webhook).

Open the new webhook and click Copy Webhook URL. You can also change its picture: it's the one shown on the alerts.Abre o webhook que foi criado e carrega em Copy Webhook URL (Copiar URL do webhook). Se quiseres, podes mudar a imagem: é a que aparece nos avisos.

3

Copy your ID (optional)Copia o teu ID (opcional)

Only needed if you want to be mentioned. Just the number, e.g. 123456789012345678.Só é preciso se quiseres ser mencionado. Basta o número, por exemplo 123456789012345678.

How to copy your IDComo copiar o ID →
4

Set it up in gameConfigura no jogo

F7 This is the key to open and edit the Kick Notifier config, in game and at any time. To use a different key, change it in Options → Controls.É a tecla para abrir e editar a config do Kick Notifier, dentro do jogo e a qualquer momento. Se quiseres outra tecla, muda-a em Opções → Controlos.

1 Paste the webhook URL. 2 Paste your ID (optional). 3 Click Save.1 Cola o URL do webhook. 2 Cola o teu ID (opcional). 3 Carrega em Guardar (Save).

FAQ

It says "Invalid mention". What do I do?Diz "Menção inválida". O que faço?

The field only accepts the numeric ID (17 to 20 digits) or <@ID>. Your username or @name won't work.O campo só aceita o ID numérico (17 a 20 dígitos) ou <@ID>. O nome de utilizador ou @nome não funcionam.

It says "Failed (code 404)".Diz "Falhou (código 404)".

The webhook was deleted or the URL wasn't copied correctly. Create a new one and paste it again.O webhook foi apagado ou o URL está mal copiado. Cria outro e cola-o de novo.
