Como funcionaHow it works

Duas peças que falam uma com a outra.Two pieces that talk to each other.

  • No PC corre um agente em Python que lê o /proc e os sensores a cada segundo.The PC runs a Python agent that reads /proc and the sensors every second.
  • A app manda uma pergunta para a rede e o PC responde com o IP e o nome.The app sends a query to the network and the PC answers with its IP and name.
  • A partir daí o widget vai buscar os valores ao PC pela porta 8085.From then on the widget fetches the values from the PC on port 8085.
  • Com vários PCs na mesma rede, escreve o IP do que queres ver.With several PCs on the same network, type the IP of the one you want to see.
  • Parar desliga a ligação e o widget deixa de atualizar.Parar (stop) ends the connection and the widget stops updating.

DúvidasFAQ

O que costuma aparecer.What usually comes up.

A app não encontra o PCThe app can't find the PC

Confirma que o PC e o telemóvel estão na mesma rede Wi-Fi e que o agente está a correr. Se continuar, escreve o IP que o instalador mostrou (com :8085).Check that the PC and the phone are on the same Wi-Fi network and that the agent is running. If it still fails, type the IP the installer showed (with :8085).

A GPU aparece com "--"The GPU shows "--"

O PC não tem placa gráfica dedicada ou não a consegue ler. Nas NVIDIA é preciso o nvidia-smi (vem com o driver), nas AMD o driver amdgpu.The PC has no dedicated graphics card or can't read it. NVIDIA needs nvidia-smi (it comes with the driver), AMD needs the amdgpu driver.

Funciona fora de casa?Does it work away from home?

Não. O telemóvel liga diretamente ao PC, por isso têm de estar na mesma rede.No. The phone connects straight to the PC, so they have to be on the same network.

Preciso de root?Do I need root?

Não. O agente instala-se só para o teu utilizador. Só a regra da firewall, se existir, pede a palavra-passe.No. The agent installs only for your user. Only the firewall rule, if there is one, asks for the password.

Funciona no Windows?Does it work on Windows?

Por agora o agente é só para Linux.For now the agent is Linux only.
